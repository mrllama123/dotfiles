# Setting up the game area

In this first part, we're going to set up the game area. Let's get started by
importing the start assets and setting up the game scene.

We've prepared a Godot project with the 3D models and sounds we'll use for this
tutorial, linked in the index page. If you haven't done so yet, you can download
the archive here: [Squash the Creeps assets](https://github.com/godotengine/godot-docs-project-starters/releases/download/latest-4.x/3d_squash_the_creeps_starter.zip).

Once you downloaded it, extract the .zip archive on your computer. Open the
Godot Project Manager and click the _Import_ button.

![../../_images/01.import_button.webp](../../_images/01.import_button.webp)

In the import popup, enter the full path to the freshly created directory
`3d_squash_the_creeps_starter/`. You can click the _Browse_ button on the right to
open a file browser and navigate to the `project.godot` file the folder
contains.

![../../_images/02.browse_to_project_folder.webp](../../_images/02.browse_to_project_folder.webp)

Click _Import_ to open the project in the editor.

![../../_images/03.import_and_edit.webp](../../_images/03.import_and_edit.webp)

A window notifying you that the project was generated by an older Godot version may appear.
Click _OK_ to convert the project to your current Godot version.

![../../_images/import_project_to_4.x_prompt.webp](../../_images/import_project_to_4.x_prompt.webp)

If it doesn't open immediately open the project from your project list.

The start project contains an icon and two folders: `art/` and `fonts/`.
There, you will find the art assets and music we'll use in the game.

![../../_images/04.start_assets.webp](../../_images/04.start_assets.webp)

There are two 3D models, `player.glb` and `mob.glb`, some materials that
belong to these models, and a music track.

## Setting up the playable area

We're going to create our main scene with a plain [Node](../../classes/class_node.md#class-node) as its root. In the
_Scene_ dock, click the _Add Child Node_ button represented by a "+" icon in the
top-left and double-click on _Node_. Name the node `Main`. An alternate method to rename the node is to right-click on _Node_ and choose _Rename_ (or `F2`). Alternatively, to add
a node to the scene, you can press `Ctrl + A` ( `Cmd + A` on macOS).

![../../_images/05.main_node.webp](../../_images/05.main_node.webp)

Save the scene as `main.tscn` by pressing `Ctrl + S` ( `Cmd + S` on macOS).

We'll start by adding a floor that'll prevent the characters from falling. To
create static colliders like the floor, walls, or ceilings, you can use [StaticBody3D](../../classes/class_staticbody3d.md#class-staticbody3d) nodes. They require [CollisionShape3D](../../classes/class_collisionshape3d.md#class-collisionshape3d) child nodes to
define the collision area. With the `Main` node selected, add a [StaticBody3D](../../classes/class_staticbody3d.md#class-staticbody3d)
node, then a [CollisionShape3D](../../classes/class_collisionshape3d.md#class-collisionshape3d). Rename the [StaticBody3D](../../classes/class_staticbody3d.md#class-staticbody3d) to `Ground`.

![../../_images/adding_static_body3D.webp](../../_images/adding_static_body3D.webp)

Your scene tree should look like this

![../../_images/06.staticbody_node.webp](../../_images/06.staticbody_node.webp)

A warning sign next to the [CollisionShape3D](../../classes/class_collisionshape3d.md#class-collisionshape3d) appears because we haven't defined
its shape. If you click the icon, a popup appears to give you more information.

![../../_images/07.collision_shape_warning.webp](../../_images/07.collision_shape_warning.webp)

To create a shape, select the [CollisionShape3D](../../classes/class_collisionshape3d.md#class-collisionshape3d) node, head to the _Inspector_
and click the _<empty>_ field next to the _Shape_ property. Create a new _BoxShape3D_.

![../../_images/08.create_box_shape3D.webp](../../_images/08.create_box_shape3D.webp)

The box shape is perfect for flat ground and walls. Its thickness makes it
reliable to block even fast-moving objects.

A box's wireframe appears in the viewport with three orange dots. You can click
and drag these to edit the shape's extents interactively. We can also precisely
set the size in the inspector. Click on the [BoxShape3D](../../classes/class_boxshape3d.md#class-boxshape3d) to expand the resource.
Set its _Size_ to `60` on the X-axis, `2` for the Y-axis, and `60` for
the Z-axis.

![../../_images/09.box_size.webp](../../_images/09.box_size.webp)

Collision shapes are invisible. We need to add a visual floor that goes along
with it. Select the `Ground` node and add a [MeshInstance3D](../../classes/class_meshinstance3d.md#class-meshinstance3d) as its child.

![../../_images/10.mesh_instance3d.webp](../../_images/10.mesh_instance3d.webp)

In the _Inspector_, click on the field next to _Mesh_ and create a [BoxMesh](../../classes/class_boxmesh.md#class-boxmesh)
resource to create a visible box.

![../../_images/11.box_mesh.webp](../../_images/11.box_mesh.webp)

Once again, it's too small by default. Click the box icon to expand the
resource and set its _Size_ to `60`, `2`, and `60`.

![../../_images/12.cube_resized.webp](../../_images/12.cube_resized.webp)

You should see a wide grey slab that covers the grid and blue and red axes in
the viewport.

We're going to move the ground down so we can see the floor grid. To do this, the grid snapping feature can be used.
Grid snapping can be activated 2 ways in the 3D editor.
The first is by pressing the _Use Snap_ button (or pressing the `Y` key).
The second is by selecting a node, dragging a handle on the gizmo **then** holding `Ctrl` while still clicking to enable snapping as long as `Ctrl` is held.

![../../_images/use_snap.webp](../../_images/use_snap.webp)

Start by setting snapping with your preferred method. Then move the `Ground` node using the Y-axis (the green arrow on the gizmo).

![../../_images/move_gizmo_y_axis.webp](../../_images/move_gizmo_y_axis.webp)

Note

If you can't see the 3D object manipulator like on the image above, ensure
the _Select Mode_ is active in the toolbar above the view.

![../../_images/14.select_mode_icon.webp](../../_images/14.select_mode_icon.webp)

Move the ground down `1` meter, in order to have a visible editor grid. A label in the bottom-left corner of the
viewport tells you how much you're translating the node.

![../../_images/15.translation_amount.png](../../_images/15.translation_amount.png)

Note

Moving the _Ground_ node down moves both children along with it.
Ensure you move the _Ground_ node, **not** the _MeshInstance3D_ or the
_CollisionShape3D_.

Ultimately, `Ground`'s transform.position.y should be -1

![../../_images/ground_down1meter.webp](../../_images/ground_down1meter.webp)

Let's add a directional light so our scene isn't all grey. Select the `Main`
node and add a child node [DirectionalLight3D](../../classes/class_directionallight3d.md#class-directionallight3d).

![../../_images/create_directional_light3d.webp](../../_images/create_directional_light3d.webp)

We need to move and rotate the [DirectionalLight3D](../../classes/class_directionallight3d.md#class-directionallight3d) node.
Move it up by clicking and dragging on the manipulator's green arrow
and click and drag on the red arc to rotate it around the X-axis, until the
ground is lit.

In the _Inspector_, turn on _Shadow_ by clicking the checkbox.

![../../_images/16.turn_on_shadows.webp](../../_images/16.turn_on_shadows.webp)

At this point, your project should look like this.

![../../_images/17.project_with_light.webp](../../_images/17.project_with_light.webp)

That's our starting point. In the next part, we will work on the player scene
and base movement.
