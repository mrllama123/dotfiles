# NoiseTexture3D

**Inherits:** [Texture3D](class_texture3d.md#class-texture3d) **<** [Texture](class_texture.md#class-texture) **<** [Resource](class_resource.md#class-resource) **<** [RefCounted](class_refcounted.md#class-refcounted) **<** [Object](class_object.md#class-object)

A 3D texture filled with noise generated by a [Noise](class_noise.md#class-noise) object.

## Description

Uses the [FastNoiseLite](class_fastnoiselite.md#class-fastnoiselite) library or other noise generators to fill the texture data of your desired size.

The class uses [Thread](class_thread.md#class-thread) s to generate the texture data internally, so [Texture3D.get\_data()](class_texture3d.md#class-texture3d-method-get-data) may return `null` if the generation process has not completed yet. In that case, you need to wait for the texture to be generated before accessing the image:

```
var texture = NoiseTexture3D.new()
texture.noise = FastNoiseLite.new()
await texture.changed
var data = texture.get_data()

```

- void **set\_normalize**(value: [bool](class_bool.md#class-bool))

If `true`, the noise image coming from the noise generator is normalized to the range `0.0` to `1.0`.

Turning normalization off can affect the contrast and allows you to generate non repeating tileable noise textures.

* * *

[bool](class_bool.md#class-bool) **seamless** = `false` [🔗](#class-noisetexture3d-property-seamless)

- void **set\_seamless**(value: [bool](class_bool.md#class-bool))

- [bool](class_bool.md#class-bool) **get\_seamless**()


If `true`, a seamless texture is requested from the [Noise](class_noise.md#class-noise) resource.

**Note:** Seamless noise textures may take longer to generate and/or can have a lower contrast compared to non-seamless noise depending on the used [Noise](class_noise.md#class-noise) resource. This is because some implementations use higher dimensions for generating seamless noise.

**Note:** The default [FastNoiseLite](class_fastnoiselite.md#class-fastnoiselite) implementation uses the fallback path for seamless generation. If using a [width](#class-noisetexture3d-property-width), [height](#class-noisetexture3d-property-height) or [depth](#class-noisetexture3d-property-depth) lower than the default, you may need to increase [seamless\_blend\_skirt](#class-noisetexture3d-property-seamless-blend-skirt) to make seamless blending more effective.

* * *

[float](class_float.md#class-float) **seamless\_blend\_skirt** = `0.1` [🔗](#class-noisetexture3d-property-seamless-blend-skirt)

- void **set\_seamless\_blend\_skirt**(value: [float](class_float.md#class-float))

- [float](class_float.md#class-float) **get\_seamless\_blend\_skirt**()


Used for the default/fallback implementation of the seamless texture generation. It determines the distance over which the seams are blended. High values may result in less details and contrast. See [Noise](class_noise.md#class-noise) for further details.

**Note:** If using a [width](#class-noisetexture3d-property-width), [height](#class-noisetexture3d-property-height) or [depth](#class-noisetexture3d-property-depth) lower than the default, you may need to increase [seamless\_blend\_skirt](#class-noisetexture3d-property-seamless-blend-skirt) to make seamless blending more effective.
